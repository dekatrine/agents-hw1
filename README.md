# ДЗ №1 — вариант A (новичок)

**Автор:** Екатерина Деева. **Дата:** 15 ноября 2026. **Модель:** `gpt-6.1-sol`, reasoning `xhigh` в обеих независимых попытках. Точный снимок модели неизвестен.

Мини-трекер учебных задач: сравнение короткого запроса и предварительной спецификации. Использована **спецификация в формате OpenSpec, без CLI**.

## Запуск

Скачайте нужный HTML через кнопку Download raw file на GitHub и откройте двойным щелчком в браузере. Установка библиотек, сервер, сборка, CDN и API-ключи не нужны.

- `tracker-v1.html` — исходная первая попытка по короткому запросу; сохранена с обнаруженными ошибками.
- `tracker-v2.html` — вторая попытка по проверенной спецификации.
- `tracker-v1-fixed.html` — отдельно сохранённое исправление первой попытки после приёмки.

В v1 используется localStorage: задачи могут сохраняться после закрытия. Для чистой проверки используйте новый профиль браузера либо удалите только данные этого учебного трекера. При `file://` сохранение зависит от браузера. В v2 данные хранятся в памяти: перезагрузка возвращает стартовый пример.

Проверки интерфейса выполнялись в Google Chrome с автоматизацией реальных пользовательских действий через локальный HTTP. Доступ к `file://` заблокирован политикой инструмента, поэтому непосредственное открытие файла с диска не заявляется как выполненная проверка. Внешние зависимости отдельно проверяются по исходникам. OpenSpec CLI и его валидатор не запускались.

Папки преподавательского стенда, API-ключи и .env в работу не включены.
