# План реализации и проверок

Все пункты ниже — предложенные работы для отдельного запроса на реализацию. Отметки выполнения пока не установлены.

## Реализация

- [ ] Создать один `tracker-v2.html` со встроенными CSS и JavaScript, без CDN, внешних библиотек и API-ключей.
- [ ] Создать основной список задач с полями `id`, `title`, `hours`, `done` и заданным стартовым примером.
- [ ] Реализовать добавление с уникальным `id` и `done=false`, удаление по `id` и переключение `done`.
- [ ] Проверять название после `trim`; проверять непустые числовые часы в диапазоне 0,5–24 с шагом 0,5.
- [ ] Показывать ошибки рядом с полями и сохранять оба введённых значения при неуспешной отправке.
- [ ] Рассчитывать все часы, выполненные часы и округлённый прогресс по полному списку; обработать пустой список без деления на ноль.
- [ ] Реализовать фильтры «Все», «Активные» (`done=false`) и «Готовые» (`done=true`), влияющие только на видимый список.
- [ ] Подписать поля и кнопки; обеспечить читаемость при ширине 390 px без горизонтального скролла.

## Предложенные проверки

- [ ] Открыть локальный файл без сети и проверить работу основных действий.
- [ ] Проверить стартовый пример: всего 8 ч, выполнено 2 ч, прогресс 25%.
- [ ] Включить «Активные»: видны «Практика» и «Повторение», показатели остаются 2/8 ч и 25%.
- [ ] Включить «Готовые» в стартовом примере: видно только «Чтение», показатели остаются 2/8 ч и 25%. Переключение между всеми тремя фильтрами не меняет общие часы и прогресс.
- [ ] Отметить «Практику» готовой: её данные меняются, выполнено 6/8 ч, прогресс 75%. Повторное переключение возвращает 2/8 ч и 25%.
- [ ] Добавить «  Конспект  » на 1,5 ч: появляется невыполненная задача «Конспект», итоговые показатели обновляются.
- [ ] Удалить задачу, в том числе при фильтре «Активные»: удаляется выбранная задача, показатели обновляются по всему списку.
- [ ] Проверить пустое название и название из пробелов: добавления нет, ошибка рядом с названием, оба значения формы сохранены.
- [ ] Проверить пустые, состоящие из пробелов и отрицательные часы: добавления нет, ошибка рядом с часами, оба значения формы сохранены.
- [ ] Проверить недопустимые часы: нечисловое или неконечное значение, 0, 0,25, 24,5 и 1,25 отклоняются.
- [ ] Проверить допустимые часы 0,5 и 24: задачи с непустыми названиями добавляются.
- [ ] Проверить округление: при задачах на 0,5 ч и 1 ч выполнение первой даёт 33%, выполнение только второй — 67%.
- [ ] Удалить все задачи: список пуст, всего 0 ч, выполнено 0 ч, прогресс 0%, `NaN` и `Infinity` отсутствуют.
- [ ] Проверить интерфейс при ширине 390 px, включая длинное название и ошибки: всё читается, поля и кнопки подписаны, горизонтального скролла нет.
